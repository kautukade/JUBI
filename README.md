# SARUS

SARUS is a local-first multi-agent AI operating platform integrating SARA, Hermes Agent, ECC, Agency Agents, Awesome LLM Apps, Second Brain Skills, Superpowers, Fable OS concepts, CAI defensive isolation, and Autoresearch evaluation workflows.

## Windows release

GitHub Actions builds the full Windows release and publishes a single ZIP in **Releases**. The release contains `SARUS-Setup.exe`, the verified payload, checksums, and installation instructions.

Core AI routing is designed for local Ollama models. Cloud-tagged Ollama models are disabled from automatic local routing.

> Security: unrestricted Ring-0 LLM execution is not enabled. Privileged Windows actions use permission/approval paths; CAI active tooling and Fable kernel experiments remain isolated/optional.
